Air quality drift watch

live

A monitoring loop that catches a model going stale. The model forecasts a city's hourly PM2.5, the fine-particulate pollution in its air, seven days ahead, using the weather forecast for that hour as it stood a week earlier. It inherits that forecast's error before adding any of its own. The loop watches it across six cities, measures drift, trains a challenger when it decays, and promotes it only if it wins on data neither has seen.

Where the data comes from

One marker per monitored city, coloured by its latest data-drift reading and sized by how many monitoring runs it has. Click a marker, or a row, to switch the dashboard to that city. Drag to rotate the globe.

Does the detection actually work?

A real city cannot answer that. Its drift has no known cause and no control condition, so a detector that fired at random would look much the same. This is the same loop run against a synthetic world with two independent knobs: one that shifts the feature distributions, and one that changes the relationship between features and pollution. Each detector should answer to its own knob and ignore the other.

How this works

The loop

One scheduled run, every week. Steps 3 and 4 only happen when step 2 says they should.

    Why two signals: data drift needs no labels and no model, which makes it the early warning. Performance drift is what triggers a retrain. Deciding “has it drifted?” by comparing the champion to a challenger would be circular, since you would need a challenger before you were allowed to decide you needed one.

    The model

    A Ridge regression answering one question: given the weather we expect in a week, how dirty will the air be? Its inputs are Open-Meteo's own archived forecasts, so the weather error a real operator would have faced is carried through rather than assumed away. It reads no past pollution. Kept small on purpose, because a simple model decays visibly when the relationship shifts where a larger one would absorb some of the drift and hide it. The modelling is not the interesting part here. The loop around it is, and it would be unchanged if you swapped in something bigger.
